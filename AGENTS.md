# Rules for AI agents

Verify: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/verify.ps1` (what CI runs: `tests/run-tests.ps1`,
then the PSScriptAnalyzer gate `tools/lint.ps1`; prints 1 final PASS or FAIL line). It takes 4 to 6 minutes: give
the shell call a 10-minute timeout or run it in the background.

AI usage taskbar widgets: Windows taskbar pills that show Claude, Codex and Antigravity plan usage (PowerShell 5.1 + WPF), plus a
macOS menu-bar app in `macos/` (Swift).

## Commands

Run them from the repo root exactly as written: forward slashes work in Git Bash and in PowerShell (in Git Bash,
`tools\verify.ps1` loses its backslash and fails).

- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/verify.ps1`: the verify command above. Lint needs
  `Install-Module PSScriptAnalyzer -RequiredVersion 1.25.0 -Scope CurrentUser` once; without it lint is skipped with a
  warning locally (never in CI).
- `powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-tests.ps1 -Suite Claude` (or `-Suite Codex`, `-Suite Antigravity`;
  no `-Suite` runs all 3): `tools/sync.ps1 -Check`, link checks, the version and packaging check, then the simulated test
  suites (fake sign-ins and CLIs, a fake local Antigravity server, no network). Exit an installed widget before running it.
- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/sync.ps1`: regenerates the Codex and Antigravity copies
  from the Claude files and checks every script parses and has a BOM; add `-Check` to change nothing and only report.
- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/lint.ps1`: the PSScriptAnalyzer gate alone.
- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/package.ps1`: builds the release zips and checksums in
  `dist/` and checks the version against `CHANGELOG.md`.
- macOS (on a Mac): `./macos/build.sh`, `./macos/test.sh` (CI: the **macOS app** workflow).

## Which check

There is no single-test command; the smallest check per change (times measured on a Windows laptop; run each script
with the `powershell -NoProfile -ExecutionPolicy Bypass -File` prefix above):

- Any `.ps1` edit: `tools/sync.ps1 -Check` (3 s): parse errors, BOM, Codex and Antigravity copies up to date.
- `claude-usage-widget/` or `shared/WidgetStrip.cs`: `tools/sync.ps1`, then `tests/run-tests.ps1 -Suite Claude` (4 min).
- `codex-usage-widget/codex-usage.ps1`: `tests/run-tests.ps1 -Suite Codex` (1.5 min).
- `antigravity-usage-widget/antigravity-usage.ps1`: `tests/run-tests.ps1 -Suite Antigravity`.
- Before the pull request: `tools/verify.ps1` (4 to 6 min; lint alone is 0.5 to 1 min).

## Layout and rules

- `claude-usage-widget/` is the source; its tests are `tests/test-claude.ps1`. In `codex-usage-widget/` and
  `antigravity-usage-widget/` everything except the collector (`codex-usage.ps1`, `antigravity-usage.ps1`) is
  generated by `tools/sync.ps1` (tests: `tests/test-codex.ps1`, `tests/test-antigravity.ps1`): never hand-edit it; edit
  the Claude file and run `tools/sync.ps1`. Each generated widget's product block (name, accent, URLs) is its `Block` text in the
  `$products` list of `tools/sync.ps1`.
- `shared/WidgetStrip.cs` is embedded in `claude-usage-widget.ps1` between `# >>> WidgetStrip.cs` and
  `# <<< WidgetStrip.cs` by `tools/sync.ps1`: edit the `.cs` file, never that block. It is the same file as in
  hw-widget and machines-widget; change all copies together.
- Tests: each is `Check '<name>' (<condition>) '<detail>'`. Collector tests run `claude-usage.ps1` as a process
  against a fake sign-in folder. Widget functions are loaded by name from the widget's syntax tree: add a new
  function's name to the `$want` list in `tests/test-claude.ps1` before calling it there.
- Scripts stay compatible with Windows PowerShell 5.1 and are saved as UTF-8 with BOM (`.editorconfig`,
  `.gitattributes`); `sync.ps1 -Check` fails otherwise.
- A version bump changes `$script:Version` in `claude-usage-widget/claude-usage-widget.ps1`, `appVersion` in
  `macos/Sources/Core.swift` and a new top section in `CHANGELOG.md` together.
- Do not run the installers or uninstallers (`Install * widget.cmd`, `*/install.ps1`, `*/uninstall.ps1`,
  `macos/install.sh`): they install into the user's session. Never paste tokens, `.credentials.json` or `auth.json`.

## Shipping

- 1 issue per piece of work, then a branch `feat/<issue>-<slug>` or `fix/<issue>-<slug>`.
- Commit subjects `feat: … (#<issue>)` or `fix: … (#<issue>)`; the pull request body says `Fixes #<issue>`.
- Squash merge once CI is green. Releases: push a `v<version>` tag on the merge commit; the **Release** workflow publishes.
